Англия предлагает ограничения только для врачей для жидких BBL, других косметических процедур

Новые предложения ограничат эстетические процедуры с высоким риском для квалифицированных медицинских работников, ограничат лечение несовершеннолетних и введут штрафы для неквалифицированных поставщиков.
