Компонент датчика глюкозы для инъекций соответствует более дорогой альтернативе за одну десятую стоимости

Для миллионов людей, живущих с диабетом, непрерывный мониторинг уровня глюкозы обеспечивает картину уровня глюкозы в режиме реального времени, помогая пользователям управлять лекарствами, диетой и повседневной деятельностью.

Но, несмотря на их преимущества, устройства остаются недоступными для некоторых пациентов из-за их стоимости.
