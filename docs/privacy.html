Политика конфиденциальности — MorozMax

Последнее обновление: 28 сентября 2026

1. Какие данные собираются

Приложение MorozMax не собирает и не хранит персональные данные пользователей. Приложение авторизует владельца аккаунта, чтобы публиковать контент от его имени.

2. Токены авторизации

После согласия пользователя приложение получает OAuth-токены TikTok (access token и refresh token). Токены хранятся только в конфигурации приложения, не передаются третьим лицам и используются исключительно для публикации видео от имени владельца. Срок действия refresh token — 365 дней, после чего требуется повторная авторизация.

3. Данные, публикуемые в TikTok

Публикуются только материалы, подготовленные самим приложением: заголовок новостной статьи, краткое описание, ссылка на источник, сгенерированный видеоролик с музыкой и озвучкой. Тексты берутся из открытых RSS-лент новостных изданий со ссылкой на первоисточник.

4. Сторонние сервисы

Перевод текста выполняется через публичный сервис машинного перевода Google Translate, изображения — через picsum.photos (при наличии ключей Pexels или Unsplash). Эти сервисы получают только текст или изображения, необходимые для формирования поста.
